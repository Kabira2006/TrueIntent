# Phase 9 Implementation Status

## Completed Components

### 1. Dataset Builder (`scripts/build_eval_set.py`) ✅
- Fetches OpenPhish, URLhaus (with terms compliance)
- Fetches Tranco top-N domains
- Samples real internal links from benign sites (path artefact mitigation)
- 20+ handwritten tricky cases (Indian context)
- Deduplication, registrable domain extraction
- **Domain-based splitting** (GroupShuffleSplit): train 60% / val 20% / test 20%
- Test split hash computed and sealed
- Outputs: `data/eval/eval_manifest.csv`, `eval_metadata.json`, `tricky_cases.csv`

**Leakage Avoidance:**
1. ✅ Path artefact: Samples real links from Tranco homepages; marks bare hosts
2. ✅ Feed-identity: No feed-encoding features
3. ✅ Domain leakage: Split by registrable_domain (no domain in both train+test)
4. ✅ Time leakage: Date field captured for time-based view
5. ✅ Dead URLs: All URLs in manifest; live subset evaluated separately

### 2. Feature Extractor (`app/ml/features.py`) ✅
- Reuses `lexical.py` for host-level features
- Adds infrastructure features (domain age, DNS, MX, TLS age)
- Nullable features with missing indicators + median imputation
- Offline mode for batch evaluation
- Two feature sets:
  - `FEATURE_COLUMNS_HOST_ONLY`: Default, no path artefact
  - `FEATURE_COLUMNS_WITH_PATH`: Optimistic variant, labelled clearly
- Saves `feature_schema.json` with descriptions

### 3. Model Trainer (`app/ml/train.py`) ✅
- Trains LogisticRegression, RandomForest, LightGBM (if available)
- **GroupKFold** cross-validation on TRAIN (domain leakage avoidance)
- Hyperparameter search with GridSearchCV
- Picks best model on VAL split
- Calibrates probabilities (isotonic regression)
- **Feature importance analysis** with leakage detection (warns if single feature >0.7)
- Saves `model_b.joblib` with metadata (training date, manifest hash, sklearn version)
- Supports both host-only and with-path feature sets
